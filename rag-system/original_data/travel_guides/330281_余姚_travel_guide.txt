# 余姚市1日游攻略

## 🏙️ 城市简介
余姚位于浙江省东北部，宁波市下辖县级市，是长江三角洲南翼的重要城市。作为河姆渡文化的发祥地，拥有7000多年文明史，是浙江省历史文化名城。春秋时期属越国，秦时置县，历史悠久。最佳旅行时间为春季（3-5月）和秋季（9-11月），气候宜人，景色优美。

## 🚗 交通指南
**到达方式**：
- 高铁：余姚北站是杭甬高铁重要站点，从杭州东站约30分钟，上海虹桥约1.5小时
- 自驾：杭甬高速、杭州湾跨海大桥连接线均可到达
- 长途汽车：宁波汽车南站有频繁班车前往，约40分钟车程

**市内交通**：
- 公交车：票价1-2元，覆盖主要景点
- 出租车：起步价10元，市区内各景点间车费约15-20元
- 共享单车：市区内投放量大，适合短距离出行

## 📅 详细行程安排

### 第1天：文化探秘与自然风光

- **上午**（9:00-12:00）：
  前往河姆渡遗址博物馆（门票免费，需预约）
  参观7000年前的史前文明遗址，了解稻作农业起源
  建议游览时间：2.5小时

- **下午**（13:30-17:00）：
  游览天下玉苑景区（门票60元）
  欣赏精美的玉石雕刻，参观西隐禅寺
  在景区内漫步，享受山水之美
  建议游览时间：3小时

- **晚上**（18:00-20:00）：
  逛余姚老城区，漫步舜水南路
  欣赏古城夜景，体验当地夜生活

- **推荐美食**：
  午餐可在河姆渡遗址附近品尝农家菜
  晚餐推荐尝试余姚特色：黄鱼面、杨梅酒

1. **余姚杨梅**（6月最佳）：国家地理标志产品，酸甜多汁
   - 推荐：梁弄镇杨梅基地现摘现吃

2. **黄鱼面**：用新鲜黄鱼熬制汤底，面条劲道
   - 推荐：老西门黄鱼面馆

3. **河姆渡茭白**：当地特产，清脆爽口
   - 推荐：农家乐清炒茭白

4. **余姚年糕**：软糯可口，可炒可汤
   - 推荐：老街年糕店
